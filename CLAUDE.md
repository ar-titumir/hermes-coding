# Claude Code

## Status card (STATUS.md)
`STATUS.md` in this folder is this project's status card. The owner's dashboard (`~/python/project-dashboard`)
reads it when the owner presses Sync, and builds the project index from it.
- Before ending a session that changed the stage, state, next action, blockers, milestones, deploy or
  schedule, update `STATUS.md` and set `updated:` to today's date (YYYY-MM-DD).
- Format and rules: `~/python/project-dashboard/STATUS-FORMAT.md`. Keep it to one screen; history stays in
  PROGRESS.md / docs.
- Honest, documented claims only (say "reported" unless you checked it this session). No secrets, tokens,
  private customer data or lead records.
